# Web-kamera Kuolimolle

16.02.2014


Etusivun linkeistä löytyy web-kamera Kuolimolle. Kuvassa näkyy Pappilanrannasta jäätien alkupää ja retkiluistelun lähtöalue. Lisäksi näkyvät säätiedot. Sivu päivittyy minuutin välein.
